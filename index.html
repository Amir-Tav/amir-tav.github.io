About

I'm a Computer Science graduate — MSc in Artificial Intelligence, First Class BSc — working across machine learning, backend engineering and cloud infrastructure.

My work has covered molecular toxicity prediction, network anomaly detection, defect detection on 3D printers and IoT automation. The thread through all of it is the same: understand the problem properly, write code that someone else can read, and ship something that still behaves when the data gets messy.
